# Changelog

## 1.0.0 - Unreleased

- Added cross-platform battery collection for macOS and Windows.
- Added SQLite measurement persistence with UTC timestamps.
- Added stoppable background monitoring with retry handling.
- Added charging and discharging session reconstruction.
- Added charge, drain, and capacity-based health analytics.
- Added a native Tkinter dashboard with charge and health history.
- Added CLI commands for collection, monitoring, session inspection, and UI startup.

## Earlier development

The project was developed incrementally before the first stable release. Earlier
development versions were not published as formal releases.
